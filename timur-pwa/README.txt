1. Завантаж цю папку на будь-який безкоштовний хостинг із https:
   - Netlify: app.netlify.com/drop -> перетягни папку timur-pwa
   - або GitHub Pages
2. Відкрий pwabuilder.com, встав адресу свого сайту, натисни Start.
3. Package for stores -> Android -> Generate Package -> завантаж .zip.
4. В архіві буде .apk (для встановлення на телефон) і .aab (для Google Play).
